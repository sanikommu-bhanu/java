---- NOTES / ANSWERS ----
ArrayList: O(1) amortised add at end, O(1) get(k), O(n) insert/remove at front/middle (array shifting, but a fast memmove). LinkedList: O(1) at the ends, O(n) get(k)/middle (pointer chasing - measured ~100x slower get). ArrayDeque: O(1) at both ends, no index access.
Boundary: ArrayList is reasonable for append-mostly + random access playlists; stop recommending it when front/middle inserts dominate and the list is large (cost grows linearly: 1000 front inserts took ~2 ms at 10k, ~19 ms at 100k).
Changed condition ('Up Next' queue, add both ends, remove front): ArrayDeque.
Space: array slot ~4 B per element vs linked node ~24-32 B; plain array with manual shifting = same O(n) as ArrayList for inserts but no auto-grow.
