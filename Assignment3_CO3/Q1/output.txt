STUDENT B (tests): 5 inputs above, each hits a different catch; finally ran every time. The stack trace is read bottom-up (main -> level1 -> level2 -> level3 -> Integer.parseInt). A broader catch before a narrower one is a COMPILE ERROR (captured below).
JOINT: catching everything with one catch (Exception e) is acceptable only at a top-level boundary that logs and shows a generic message; it loses the ability to react differently (retry for IO, re-prompt for bad input) and can hide bugs.
ALTERNATIVE (error codes): same checks written as if-chains (more visible checks, callers can forget to test the code); creating+throwing an exception costs ~500 ns and captures a stack trace (O(depth) time/space), a code check ~5 ns (O(1)).
