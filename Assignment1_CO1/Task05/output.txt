---- NOTES / ANSWERS ----
static ticket counter: one number series for the whole university; an instance counter would give north gate 1001 and south gate 1001 (duplicates, shown above).
static method needs no object (getTotalOccupancy); the static block runs once when the class is loaded.
Object life cycle: a ticket becomes eligible for garbage collection when no reference reaches it (WeakReference demo above). Java is pass-by-value: the REFERENCE is copied, so a method can change the object's state but cannot make the caller's variable point elsewhere.
Space of the counter: static O(1); instance counter O(k) for k facilities (and a shared static/AtomicInteger or a TicketService is needed for global uniqueness).
