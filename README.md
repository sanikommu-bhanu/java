# Programming in Java (CSA09) - Assignments 1 to 5

Folders: `Assignment1_CO1` ... `Assignment5_CO5`; each contains one folder per task with the source code and an `output.txt`.

Before submitting: replace the sample name/register number in each README, create the GitHub repository for each assignment
(`CSA09-<RegisterNumber>-AssignmentN`), commit task by task, re-run every program on your own machine and attach your own screenshots.
Outputs here were generated with OpenJDK 21; GUI and MySQL parts are marked as SAMPLE output where they could not run.

Run everything: `./run_all.sh` (Linux/macOS, needs JDK 17+).
